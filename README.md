# YSM 模型預覽器 / 模型管理器

一個離線的 Yes Steve Model（YSM）模型工具，分成兩部分：

- **YSM 模型管理器**（Windows 應用程式）：`dist\YSM模型管理器.exe`，用來整理你收藏的模型
- **YSM 模型預覽器**（網頁）：`index.html`，3D 預覽未加密的模型，也內建在管理器裡

## YSM 模型管理器

直接執行 `dist\YSM模型管理器.exe`，不需要安裝 Python。需要 Windows 10/11 內建的 Edge WebView2。

1. 第一次開啟會自動偵測遊戲的 `yes_steve_model` 資料夾（官方啟動器、PCL/HMCL 版本隔離、CurseForge、Prism、Modrinth），按「加入」即可。
   也可以按「新增資料夾」選 `.minecraft`、版本或實例資料夾、`yes_steve_model` 或 `custom`。
2. 模型以卡片顯示。點一下看詳細資料，雙擊可 3D 預覽（資料夾 / zip 模型）。

功能：

- **縮圖**：拖入圖片、Ctrl+V 貼上、「選擇圖片」，或「從遊戲截圖選」（自動找到遊戲的 `screenshots` 資料夾，F2 截圖後直接挑）。可拖曳、滾輪裁切。
  未加密模型可在 3D 預覽中調好角度後「把目前畫面設為縮圖」，或用「批次產生縮圖」一次全部產生。
- **整理**：標籤、1~5 星評分、自訂顯示名稱、備註（購買來源、價格、授權條件…），可依標籤、狀態、格式篩選與搜尋。
- **模型倉庫＋多實例安裝**：設定一個倉庫資料夾（例如 `D:\YSM倉庫`）集中存放所有模型，再安裝到各個遊戲實例（整合包）。
  - 安裝方式：**硬連結**（推薦，所有實例共用同一份檔案，不佔額外空間；倉庫與遊戲需在同一個 NTFS 磁碟）或**複製**。
  - 「把實例中的模型全部加入倉庫」：一次把現有模型收進倉庫；硬連結模式下會把實例中的檔案換成連結，釋放重複空間。
  - 每個實例旁的「全裝」可一次安裝倉庫全部模型；模型詳細資料中可逐一安裝或移除。
  - 「移除」只會在倉庫中確認有完全相同的內容時才刪除實例中的檔案，避免遺失。
  - 硬連結做不到時（倉庫和遊戲不在同一個 NTFS 磁碟，例如倉庫在 exFAT 外接硬碟），會先詢問是否改用複製。
  - 「從倉庫刪除」：在倉庫模型的詳細資料中，需確認兩次；能用資源回收筒的磁碟會移到回收筒，隨身碟等沒有回收筒的會直接刪除（會特別提醒）。已安裝到實例中的那份不受影響。
- **設定**（左上角 ⚙）：語言（目前只有繁體中文）、是否在改用複製前詢問、刪除時是否確認兩次、模型倉庫位置，以及管理器資料（標籤、評分、備註、縮圖）的存放位置，可搬到其他資料夾（例如雲端同步資料夾）。
  - 倉庫不能放在遊戲資料夾裡面。
- **遊戲內截圖**（加密 `.ysm` 也適用）：管理器在遊戲裡用 `/ysm model set @s <模型ID> - true` 逐一切換模型，再把遊戲畫出來的角色存成縮圖。模型由遊戲本身顯示，不讀取加密內容。有兩種模式：

  **配套 MOD 模式（推薦）**：用本專案的 YSM Shot MOD 連接遊戲，角色會被單獨畫在**透明背景**上、自動裁切，截圖時可以照常使用電腦。
  1. 用啟動器（PCL / HMCL / Prism…）建一個 **Forge 1.20.1** 實例，只放 **YSM** 一個 MOD，啟動一次讓它產生 `config\yes_steve_model`。
  2. 在管理器左側「遊戲實例」加入這個實例，用「全裝」或逐一安裝要拍的模型。
  3. 「遊戲內截圖」→ 選「配套 MOD」→ 選這個實例 →「安裝 MOD」（把 `ysmshot-forge-1.20.1-1.0.jar` 放進它的 `mods`）。
  4. 啟動遊戲，進入單人世界（**允許作弊**，或用 `/op` 給自己權限），按 <kbd>F3</kbd>+<kbd>P</kbd> 關閉「失去焦點時暫停」。
  5. 回到管理器按「檢查連線」→「試拍第一個」→「開始批次截圖」。可調整角色大小與角度（正面 / 斜側 / 背面）。
  - 遊戲回應的訊息（例如找不到模型）會顯示在該模型下方並標黃色，通常代表模型 ID 要修改。
  - YSM Shot 只在本機 127.0.0.1 開一個連接埠，連線資訊與隨機密碼寫在實例的 `config\ysmshot.json`；只會切換模型（透過 YSM 自己的指令）和畫出玩家，不讀取、不修改任何模型檔案。
  - 原始碼在 `ysmshot-mod\`（Forge 1.20.1 MDK）。重新編譯：安裝 JDK 17 後在該資料夾執行 `gradlew build`，成品在 `build\libs\`，再複製到 `mods\` 後重新打包管理器。

  **按鍵模擬模式**（不裝 MOD，任何版本可用）：管理器打開遊戲聊天欄輸入指令並按 F2 截圖。
  1. 進入單人世界（建議超平坦、創造、允許作弊），F5 切正面視角、F1 隱藏介面、輸入法切英文。
  2. 按工具列「遊戲內截圖」，選遊戲視窗與實例，先「試拍第一個」確認模型有切換並框出縮圖範圍，再「開始批次截圖」。
  3. 執行中不要動鍵盤滑鼠；切到其他視窗會自動停止。
  - YSM 的模型 ID 是「相對於 `custom` 資料夾的路徑」，檔案要含副檔名，例如 `分類/角色.ysm`；管理器會自動使用這個 ID，含中文或空白時自動加上引號。
  - 配套 MOD 模式按「檢查連線」時，會從遊戲讀取實際載入的模型 ID 清單；遊戲中沒有的（例如 YSM 因內容重複而沒載入的檔案）會標紅框，批次截圖時略過。
  - ID 不對時可在清單中修改（會記住），可在遊戲中輸入 `/ysm model set @s ` 再按 Tab 查看正確 ID。
  - 指令範本可自訂，`{id}` 為模型 ID、`{tex}` 為材質（`-` 為預設材質）。
- **啟用 / 停用**：停用會把模型移到 `yes_steve_model\ysm_manager_disabled\`，遊戲就不會載入；啟用時移回原位。
- **重新命名**、**在檔案總管中顯示**。
- 標籤、縮圖等資料依「模型內容」記錄，搬移或改名後不會遺失。資料存在 `%APPDATA%\YSMModelManager`。

加密的 `.ysm` 只會顯示檔名、大小、日期，以及官方格式中未加密的公開摘要（如果有的話）；
3D 外觀請在遊戲內的 YSM 選單查看，再用截圖當縮圖。本程式不會、也無法解密 `.ysm`。

重新打包：安裝 Python 後執行 `pip install pywebview pyinstaller`，再執行 `build.bat`。

## YSM 模型預覽器（網頁版）

## 使用方式

1. 雙擊 `啟動預覽器.bat`，或直接用瀏覽器（Chrome / Edge）打開 `index.html`。
2. 把模型**資料夾**或 **.zip** 拖進視窗，或用右上角的「開啟資料夾」/「開啟 .zip」按鈕。
3. 一個 zip 或資料夾中若有多個模型（模型包），左側清單可切換。

## 支援的格式

| 格式 | 說明 |
| --- | --- |
| 2.x 資料夾 / zip | 根目錄有 `ysm.json`，依其中 `files` 設定讀取模型、貼圖、動畫 |
| 1.x 舊版資料夾 / zip | `main.json`、`arm.json`、`*.animation.json`、`*.png` |
| 模型包 | 一個資料夾或 zip 內含多個模型（含巢狀 zip） |
| `.ysm` | **不支援**。這是官方的加密格式，設計上無法還原 |
| `.7z` | 請先解壓縮再拖入 |

## 功能

- 基岩版幾何：骨骼階層、方塊旋轉、inflate、mirror、box UV 與逐面 UV
- 基岩版動畫：關鍵影格（linear / catmullrom / step、pre/post）、loop、Molang 運算式
- 自動疊加 `pre_parallel*` / `parallel*` 並行動畫（眨眼、物理等）
- 切換目標：玩家模型、第一人稱手臂、投射物、載具
- 切換貼圖、顯示 `extra_animation` 輪盤動畫名稱
- 模擬狀態：頭部俯仰／轉向、移動速度、潛行、主副手持物
- `ysmGlow` 開頭的骨骼以發光（不受光照）呈現
- 骨骼顯示／隱藏、線框、鏤空模式、背景顏色、截圖存成 PNG
- 顯示模型資訊：名稱、說明、授權、作者（含頭像與連結）

操作：左鍵拖曳旋轉、右鍵拖曳平移、滾輪縮放、空白鍵播放/暫停。

## 限制

- Molang 是簡化版直譯器；遊戲內才有的查詢值（例如 `ysm.*` 的部分數值）以固定值或 0 代替，
  依賴這些值的物理或特效動畫可能和遊戲內不同。
- 不執行動畫控制器（`controller/`）與 `functions/*.molang`，也不播放音效。
- 不渲染手持物品、粒子與 PBR 法線/高光貼圖。

```
dist/YSM模型管理器.exe  打包好的應用程式
manager_app.py      管理器後端（掃描、資料庫、檔案操作、本機伺服器、視窗）
manager.html        管理器介面
css/manager.css     管理器樣式
js/manager.js       管理器介面邏輯
build.bat           打包腳本
mods/               打包進管理器的 YSM Shot MOD（ysmshot-forge-1.20.1-1.0.jar）
ysmshot-mod/        YSM Shot MOD 原始碼（Forge 1.20.1）
index.html          預覽器主頁面
css/style.css       預覽器樣式
js/molang.js        Molang 直譯器
js/loader.js        讀取資料夾 / zip，解析 ysm.json 與舊版格式
js/model.js         基岩版幾何 → three.js
js/animator.js      基岩版動畫播放
js/app.js           介面與場景
lib/                three.js r147、OrbitControls、JSZip 3.10.1（已內附，可離線使用）
```
